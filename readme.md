# wiimenu-gcn-hack

Priiloader hack to use GameCube controllers on the wii menu, works on 4.3u, 4.3e, and 4.3j. 4.3k support will be added in the near future.

## Installation

Append the contents of `gcn.ini` to the end of your `hacks_hash.ini`

## Background Info

This hack would not have been possible (for me to make at least) without [koopthekoopa's wii-ipl decompilation project](https://github.com/koopthekoopa/wii-ipl). Many thanks to him!
